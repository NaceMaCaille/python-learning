Reminder creation

**Reminder creation** - це консольна програма яка створює списки нагадування та зберігає їх у базу данних

## Можливості

-Створювати записи нагадувань
-Редагувати нагадування
-Оновлювати статус нагадуваня 
-Видаляти нагадування
-Отримати всі свторені нагадування у консолі

## Встановлення та запуск

git clone https://github.com/NaceMaCaille/python-learning/tree/main/Project
зміна дерикторії - cd Project
запустити - .\main.py

## Приклад використання 

Цифри відповідають за дії

## Залежності
 
Код може не спрацювати якщо не встановленна бібліотека pytz
команда для встановлення pytz - pip install pytz

## Стан Программи 

Програма ще у розробці і буде доповнюватись різними функціями
Зараз розробляється сортування по списку нагдуваня та по даті
